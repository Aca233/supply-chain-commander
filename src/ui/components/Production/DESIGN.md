# 生产管理页面 UI 重构设计

## 1. 问题诊断

### 空间问题根因
- 当前三栏常驻布局：Sidebar(240px) + Catalog(256px) + Detail(320px) = 816px 固定占用
- 1280px 窄桌面仅剩 464px 内容区，只够 1 列卡片
- 建筑卡片高度 350-450px，一屏最多看 2 个建筑
- 卡片内嵌了产量控制(Switch+Slider) 和生产方式面板，增加了 ~150px 高度

### 信息优先级分析
玩家核心循环：**扫描所有建筑状态 → 发现问题 → 进入详情调整**

| 优先级 | 信息 | 卡片必须显示 |
|--------|------|-------------|
| P0 | 建筑名/等级/状态 | ✅ |
| P0 | 效率 | ✅ |
| P0 | 日利润 | ✅ |
| P1 | 资源瓶颈指示 | ✅ (简化) |
| P1 | 产出速率 | ✅ (简化) |
| P2 | 生产方式图标 | ✅ (仅图标) |
| P3 | 产量控制 | ❌ → 移到详情 |
| P3 | 输入资源进度条 | ❌ → 移到详情 |
| P3 | 升级按钮 | ❌ → 移到详情 |

## 3. 建筑卡片设计

### 视图模式 A: 网格卡片 (~130px 高)

```
┌─────────────────────────────────────┐
│ 🏭 钢铁厂       Lv.2    ● 生产中   │ ← 行1: 名称/等级/状态
│ ████████████████░░ 92%    ¥12.5K/日 │ ← 行2: 效率条 + 日利润
│ 📥 铁矿石 90%  煤炭 ⚠45%          │ ← 行3: 输入瓶颈(仅显示≤2个最缺的)
│ 📤 钢材 +240/日    [🔧][⚡][🤖]    │ ← 行4: 主要产出 + 方式图标
└─────────────────────────────────────┘

状态颜色：左边框 2px
  active → green
  warning → amber  
  error → red
  idle → gray
```

核心压缩手段：
- 去掉图标容器(48px方块) → 用 emoji + 文字
- 效率条和利润放同一行
- 输入资源不用进度条，改为文字+百分比，瓶颈标黄
- 产出和生产方式放同一行
- 产量控制、升级按钮全部移到详情

┌─ header ──────────────────────────────────────────────────────────────┐
│  建筑名       等级  状态    效率    输入状态    产出/日    日利润     │
├───────────────────────────────────────────────────────────────────────┤
│ 🏭 钢铁厂    Lv.2  ● 生产  ██ 92%  ✅ 充足    钢材+240   ¥12.5K    │
│ ⛏ 铁矿场    Lv.1  ⚠ 低效  ██ 45%  —         铁矿+100   ¥2.1K     │

## 4. 生产概览 — 压缩为统计栏

从独立 Card 改为工具栏内嵌的统计 badge 行：

```
[⚡日产能 ¥1.0K] [🔧 运营 3/5] [⚠️ 瓶颈 1] [💰 日利润 ¥988] [📈 效率 85%]
```

- 用 Badge/StatWidget compact 模式
- 时间范围切换(日/周/月)用小下拉
- 点击某个统计可快速筛选(如点瓶颈→只显示有瓶颈的建筑)

## 5. 交互流程

```
生产管理页面
  │
  ├─ 默认: 扫描卡片网格，一眼看到所有建筑状态
  │
  ├─ 发现问题 → 点击卡片
  │    └─ 右侧 overlay 打开建筑详情
  │         ├─ 查看/调整产量控制
  │         ├─ 查看/调整生产方式
  │         ├─ 查看劳动力状况
  │         ├─ 升级建筑
  │         └─ 拆除建筑
  │
  ├─ 建造新建筑 → 点击 [+建造]
  │    └─ 左侧 overlay 打开建筑目录
  │         └─ 点击建筑 → BuildModal 弹窗
  │
  └─ 查看建造进度 → 点击 [建造队列(N)]
       └─ 底部 overlay 打开队列面板
```

## 6. 组件拆分

### 页面层
- `Production.tsx` — 页面壳：工具栏 + 内容区 + overlay 控制
- `useProductionPageState.ts` — hook: 面板状态、store 同步、回调

### 工具栏
- `ProductionToolbar.tsx` — 标题 + 统计行 + 操作按钮 + 视图切换

### 卡片
- `BuildingCardGrid.tsx` — 网格视图卡片 (~130px)
- `BuildingCardRow.tsx` — 表格视图行 (~44px)
- (旧 BuildingCard.tsx 可保留为兼容，但新页面不使用)

### 详情 (overlay 内容)
- `BuildingDetailPanel.tsx` — 壳 + section 编排
- `BuildingDetailHeader.tsx` — 图标/名称/状态/效率
- `BuildingDetailFinancials.tsx` — 收支数据
- `BuildingDetailResources.tsx` — 输入/输出详情
- `BuildingDetailLabor.tsx` — 劳动力管理
- `DemolishConfirmDialog.tsx` — 拆除确认
- (升级弹窗已有 BuildingUpgradePanel.tsx)

### 共享
- `useBuildingData.ts` — hook: 统一建筑数据计算
- `methodIconMap.ts` — 生产方式图标映射
- `formatMoneyCompact` — 在 `format.ts` 中
