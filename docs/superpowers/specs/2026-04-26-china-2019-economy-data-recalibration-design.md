# 中国 2019 经济数据重标定设计

日期: 2026-04-26

## 背景

当前项目已经具备完整的企业经营主循环：

- 商品定义位于 `src/data/goods.ts`
- 建筑与投入产出位于 `src/data/buildings.ts`
- 居民需求分层位于 `src/core/economy/DemandCurve.ts`
- 宏观事件和商业周期位于 `src/core/economy/BusinessCycle.ts`
- 银行利率与授信参数位于 `src/core/finance/BankingSystem.ts`
- 初始经济参数位于 `src/core/balance/BalanceConfig.ts`

现有系统的问题不在于“没有经济模拟”，而在于数值底盘更接近通用工业沙盒：

- 商品相对价格偏游戏化，部分行业层级关系失真
- 建筑产出、成本和建造门槛没有充分体现中国 2019 年的产业结构
- 居民消费分层存在，但收入规模、结构和消费倾向仍偏抽象
- 新能源、高端制造、奢侈消费等权重偏高，不够符合 2019 中国的总盘子
- 地产基建、传统制造、出口装配、煤电底盘的现实权重不够突出

用户本次需求不是重写经济逻辑，而是让现有系统“跑出来更像中国 2019”。

## 目标

- 保留当前企业经营玩法和系统结构
- 仅通过数据重标定，让市场表现更接近中国 2019 年的全国缩略模型
- 优先保证真实的相对关系，而不是追求所有产业都同样好玩
- 让地产基建链、煤电链、传统制造链、出口装配链回到更真实的位置
- 让居民消费结构、利率环境和宏观事件更接近 2019 中国

## 非目标

- 本次不新增政府、国企、地方财政、土地财政等新架构模块
- 本次不修改订单撮合、价格引擎、消费流程、生产流程的核心逻辑
- 本次不新增新的经济系统面板或规则系统
- 本次不追求逐项复刻统计年鉴的名义值，只追求可信的相对关系
- 本次不保证所有行业都同样容易盈利

## 核心决策

### 模型边界

本次采用：

- 中国 2019 年全国缩略模型
- 保留现有玩法中的玩家企业经营视角
- 只改数据，不改系统逻辑
- 真实优先于玩法平衡

### 真实优先的含义

“真实优先”在本次设计中的含义是：

- 优先保证价格、产出、成本、建造门槛的相对关系真实
- 允许不同产业的利润率明显不均衡
- 允许部分行业更重资产、更薄利润、更慢回本
- 不为了让每条产业链都好玩而人为抹平行业差异

## 总体方法

本次采用“数据底盘重标定”的方法，而不是结构重构。

也就是说：

- 不重写 `PriceEngine`
- 不重写 `ConsumerMarket`
- 不重写 `BankingSystem`
- 不重写 `BusinessCycle`
- 不新增“中国模式”运行时系统

而是通过调整这些系统读取的数据，改变它们最终表现出来的经济结构。

## 数值标尺

项目当前已经采用 `1 tick = 1天`。因此本次所有数据重标定都以“日”为尺度。

### 价格标尺

价格不追求逐项还原现实中的名义市场报价，而是追求以下真实关系：

- 煤炭、电力、水泥、建材、玻璃应处于低单价区
- 钢材和基础化工应处于中低单价、大流量区
- 电子元件、设备、汽车、医疗设备应处于高附加值区
- 食品、饮料、药品应体现刚需和稳定性
- 奢侈品和前沿产业应保留高价，但不主导总经济盘面

### 产出标尺

产出采用日吞吐逻辑：

- 重工业、高耗能、基础原材料建筑应高产量、低单价
- 轻工和大众消费制造应中等产量、中等附加值
- 高端制造和复杂装备应低产量、高单价、长周期

### 成本标尺

运营成本按行业画像区分，而不是统一拉平：

- 钢铁、水泥、炼油、化工更依赖能源
- 纺织、服装、装配、零售更依赖人工
- 芯片、制药、医疗器械更依赖维护和资本性成本

### 建设标尺

建造成本和建设周期体现资本密度：

- 零售、轻工、基础加工较轻
- 食品、纺织、普通制造居中
- 汽车、化工、钢铁、炼油、发电、制药明显更重

## 数据面拆分

本次重标定分为 6 个数据面。

### 1. 商品价格与弹性

文件：

- `src/data/goods.ts`

调整内容：

- `basePrice`
- `priceElasticity`
- `incomeElasticity`

目标：

- 让商品相对价格更接近中国 2019 的产业结构
- 让必需品、耐用品、奢侈品、工业品的价格弹性更合理
- 让收入弹性更接近现实消费升级路径

### 2. 建筑投入产出

文件：

- `src/data/buildings.ts`

调整内容：

- `inputs`
- `outputs`
- `ticksRequired`

目标：

- 让上游资源、中游材料、下游制造之间的吞吐关系更真实
- 让煤电、钢铁、建材、炼化成为高吞吐底盘
- 让手机、家电、汽车、药品体现更真实的单位产出和生产节奏

### 3. 运营成本结构

文件：

- `src/data/buildings.ts`

调整内容：

- `laborCost`
- `energyCost`
- `maintenanceCost`
- `powerConsumption`

目标：

- 用成本结构体现中国 2019 的行业差异
- 让高耗能行业、高人工行业、高资本行业有不同画像

### 4. 建造成本与建设周期

文件：

- `src/data/buildings.ts`
- `src/data/buildingMaterials.ts`

调整内容：

- `buildCost`
- `buildTime`
- `upgradeCosts`
- 建造材料消耗

目标：

- 让重资产行业门槛更真实
- 让地产基建链和大型工业项目的投资决策更有现实感

### 5. 居民消费分层

文件：

- `src/core/economy/DemandCurve.ts`

调整内容：

- `CONSUMER_TIERS`
- 各层收入、人口、储蓄率
- `budgetShares`
- 人均消费率表

目标：

- 让中低收入群体占比更大
- 让必需消费比重更高
- 让可选消费和升级消费受收入层级影响更明显

### 6. 宏观初值与事件参数

文件：

- `src/core/economy/BusinessCycle.ts`
- `src/core/finance/BankingSystem.ts`
- `src/core/balance/BalanceConfig.ts`
- `src/core/world/WorldInitializer.ts`

调整内容：

- 初始 GDP、人口、利率、信用额度、居民资金池
- 事件概率、持续时间、影响幅度
- 开局库存、订单热度、企业起点

目标：

- 让宏观环境更像 2019 中国
- 让地产基建、制造出口、居民消费三类力量的权重更真实

## 方向性调整结论

第一轮改动后的经济结构应明显体现以下变化：

- 煤电和建材更重
- 钢铁和化工更基础
- 手机家电和出口制造更强
- 燃油车强于电动车
- 大众消费强于升级消费
- 食品和基础药品更稳
- 新能源、高端消费、奢侈品整体降权

## 调整顺序

为了避免价格、产出、成本互相打架，按以下顺序实施：

1. 先重标核心商品价格和弹性
2. 再按价格倒推核心建筑投入产出
3. 再重标运营成本和电耗
4. 再重标建造成本、升级成本、建设周期
5. 再重标居民分层、消费率、宏观事件和融资参数
6. 最后检查是否需要扩展到剩余商品和建筑

## 验证标准

改完后，系统应该表现出以下结果：

- 建材、钢铁、煤电成为低价大体量底盘
- 地产基建链对工业需求的拉动明显增强
- 手机家电制造更强，但芯片更贵更慢
- 燃油车在 2019 背景下强于电动车
- 食品、药品、基础消费更稳、更抗周期
- 新能源、高端消费、奢侈品不会异常强势
- 重工业和基建链更顺周期，消费链更稳定

## 风险与边界

### 风险 1：真实优先导致局部玩法变“难看”

真实结构可能让部分行业：

- 利润更薄
- 投资回收更慢
- 波动更大

这是本次需求允许的结果，不单独视为 bug。

### 风险 2：只改数据可能暴露旧逻辑的失真

当价格和产出回归现实后，部分逻辑可能显得过强或过弱，例如：

- 某些需求公式放大过度
- 某些成本结算过轻
- 某些开局库存不再合理

本次只允许通过继续调数据缓解，不在第一阶段改逻辑。

### 风险 3：单位口径不完全真实

当前商品单位存在“吨、件、台、度、盒”等混合口径，且不是完整国民经济核算单位。

因此本次不要求名义值逐项还原现实，只要求：

- 相对关系可信
- 产业地位可信
- 盈利结构可信

## 验收标准

- 只通过数据修改，不引入新的经济逻辑模块
- 商品相对价格、产出、成本、建设门槛更接近中国 2019
- 地产基建链、煤电链、传统制造链、出口制造链权重显著提升
- 居民消费分层和基础消费稳定性更接近现实
- 新能源和高端消费在第一轮不再主导经济盘面
