# 生产方式系统重构计划

## 目标
为每种建筑类型（107种）设计专属的生产方式套组，让每种建筑有独特的技术升级路径和游戏体验。

---

## 一、新架构设计

### 1.1 核心变化

**现有架构问题：**
- 5种通用槽位类型（工艺、自动化、能源、品质、环保）
- 约20种通用生产方式，所有建筑共用
- 输入/输出修正使用 `goodsId=0` 占位符，无法针对特定商品

**新架构设计：**
- **专属槽位类型**：每种建筑有2-4个专属槽位
- **专属生产方式**：每个槽位有3-5个专属选项
- **针对性修正器**：可以针对特定商品ID进行修正
- **预计总方式数**：约 500-800 种专属生产方式

### 1.2 新数据结构

```typescript
// 专属槽位类型定义
interface BuildingSlotType {
  id: string;                    // 如 'steel_process', 'mining_method'
  buildingTypeId: number;        // 所属建筑类型ID
  name: string;                  // 显示名称，如 "炼钢工艺"
  icon: string;                  // 图标
  description: string;           // 槽位描述
}

// 专属生产方式定义
interface BuildingProductionMethod {
  id: number;                    // 全局唯一ID
  key: string;                   // 唯一标识
  name: string;                  // 显示名称
  buildingTypeId: number;        // 适用的建筑类型
  slotId: string;                // 所属槽位ID
  
  // 资源修正 - 可指定具体商品ID
  inputModifiers: {
    goodsId: number | 'all';     // 商品ID或'all'表示所有
    multiplier: number;          // 消耗倍率
  }[];
  outputModifiers: {
    goodsId: number | 'all';
    multiplier: number;
  }[];
  
  // 成本修正
  laborMultiplier: number;
  energyMultiplier: number;
  maintenanceMultiplier: number;
  
  // 特殊效果
  qualityBonus: number;
  pollutionMultiplier: number;
  productionSpeedMultiplier: number;  // 新增：生产速度修正
  byproductChance?: number;           // 新增：副产品几率
  byproductGoodsId?: number;          // 副产品商品ID
  
  // 解锁条件
  requiredLevel: number;
  requiredResearch?: string;          // 新增：需要解锁的科技
  
  // 成本
  switchCooldown: number;
  switchCost: number;
  
  description: string;
}
```

## 五、数值设计原则

1. **渐进升级**: 高级方式需要更高建筑等级解锁
2. **权衡取舍**: 没有绝对最优方式，不同方式适合不同策略
3. **行业特色**: 方式名称和效果体现真实行业特点
4. **经济平衡**: 高级方式的收益覆盖切换成本需要合理时间
