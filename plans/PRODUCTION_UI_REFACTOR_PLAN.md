# 生产管理界面全面重构方案

## 🎯 设计目标

打造类似《维多利亚3》和《工厂模拟器》风格的专业生产管理界面：
- **信息层次清晰**：一眼看到最重要的数据
- **视觉美观现代**：使用渐变、动画、图标增强视觉吸引力
- **交互流畅直观**：减少点击次数，提供即时反馈
- **数据可视化丰富**：进度条、状态指示、趋势图表

## 🎨 组件详细设计

### 1. 生产概览统计面板 (ProductionOverview)

位于主区域顶部，展示关键生产指标：

```
┌─────────────────────────────────────────────────────────────────────┐
│  📊 生产概览                                            [日/周/月] │
├─────────────┬─────────────┬─────────────┬─────────────┬─────────────┤
│  ⚡ 日产能   │  🔧 运营建筑 │  ⚠️ 瓶颈数   │  💰 日利润   │  📈 综合效率 │
│  ¥1.25M     │  12/15 座   │  3 个       │  ¥280K      │  87.5%     │
│  ↑12.3%     │  80%运转    │  需关注     │  ↑5.2%      │  ↓2.1%     │
├─────────────┴─────────────┴─────────────┴─────────────┴─────────────┤
│  资源流向简图: [铁矿]→[钢材]→[零部件]→[汽车]  产能: 充足 ✓         │
└─────────────────────────────────────────────────────────────────────┘
```

**组件特性：**
- 使用渐变背景卡片
- 数字使用大字体，变化趋势用颜色标识
- 悬停显示详细数据
- 可折叠/展开

├───────────────────────────────────────┤
│  📥 输入                  📤 输出      │

│  煤炭   ██████████ 100%  副产品 +23/日 │
├───────────────────────────────────────┤
│  生产方式槽位:                         │
│  [⚙️ 机械化] [⚡ 电力] [⭐ 标准] [🌿 -] │

- 点击卡片展开详情面板
- 悬停显示快捷操作
- 拖拽调整顺序（可选）

## 🔄 交互设计

### 快捷操作

| 操作 | 触发方式 | 效果 |
|------|----------|------|
| 选中建筑 | 单击卡片 | 右侧展开详情面板 |
| 快速升级 | 点击升级按钮 | 直接升级（有确认） |
| 更换配方 | 双击配方区域 | 打开配方选择器 |
| 暂停/恢复 | 点击状态图标 | 切换生产状态 |
| 批量选择 | Ctrl+单击 | 多选建筑 |
| 快速建造 | 双击目录建筑 | 打开建造弹窗 |

### 拖拽功能（可选）

- 拖拽建筑卡片调整显示顺序
- 拖拽目录建筑到主区域快速建造

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `/` 或 `Ctrl+K` | 聚焦搜索框 |
| `G` | 切换到网格视图 |
| `L` | 切换到列表视图 |
| `N` | 打开新建建筑面板 |
| `Esc` | 关闭弹窗/取消选择 |
| `1-5` | 快速选择槽位 |
