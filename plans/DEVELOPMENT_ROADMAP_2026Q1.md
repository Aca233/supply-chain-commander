#### 任务14：科技树框架

**目标**：创建基础科技研发系统

**数据结构设计**：
```typescript
interface Technology {
  id: number;
  name: string;
  category: 'production' | 'logistics' | 'finance' | 'ai';
  prerequisites: number[];  // 前置科技ID
  researchCost: number;     // 研发成本
  researchTime: number;     // 研发周期（tick）
  effects: TechEffect[];    // 解锁效果
}
```

**科技类别**：
1. **生产科技**：提升产能、降低消耗
2. **物流科技**：加快运输、降低仓储成本
3. **金融科技**：降低贷款利率、提升投资收益
4. **AI科技**：解锁自动化功能
