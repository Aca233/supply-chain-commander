# 产业链缺失问题修复计划

## 问题概述

用户报告以下商品没有进入产业链（没有公司生产和销售）：
- 水产、家禽、水果、药材
- 金矿石、钻石矿石
- 香料原料
- 镍矿石、锡矿石、钴矿石、锰矿石、钨矿石
- 亚麻、羽绒、大理石
- 葡萄、咖啡豆、烟叶、油料作物
- 生物质

## 根本原因分析

经过对比 `goods.ts`、`recipes.ts` 和 `WorldInitializer.ts`，发现存在**严重的商品ID偏移问题**。

### 问题1：矿业扩展 (ID 128-143) 偏移

**goods.ts 正确的ID定义：**
```
锌矿石 = 128, 镍矿石 = 129, 锡矿石 = 130
钴矿石 = 131, 锰矿石 = 132, 钨矿石 = 133
锌 = 134, 镍 = 135, 锡 = 136
钴 = 137, 锰 = 138, 钨 = 139
```

**WorldInitializer.ts 错误的配置：**
```javascript
// 多金属矿业 - 错误
outputGoods: [132, 133, 134, 135, 136, 137], // 实际是 锰矿石、钨矿石、锌、镍、锡、钴

// 应该修正为
outputGoods: [128, 129, 130, 131, 132, 133], // 锌矿石、镍矿石、锡矿石、钴矿石、锰矿石、钨矿石
```

### 问题2：纺织扩展 (ID 140-149) 偏移

**goods.ts 正确的ID定义：**
```
羊毛 = 140, 亚麻 = 141, 生皮 = 142
羽绒 = 143, 毛纱 = 144, 麻布 = 145
皮革 = 146, 毛织品 = 147, 皮具 = 148, 鞋类 = 149
```

**WorldInitializer.ts 错误的配置：**
```javascript
// 羊毛纺织 - 错误
outputGoods: [144, 145, 146], // 实际是 毛纱、麻布、皮革

// 应该修正为
outputGoods: [140, 141, 143], // 羊毛、亚麻、羽绒
```

### 问题4：农产品深加工 (ID 160-175) 偏移

### 问题6：popularGoods 列表中的ID错误

`generateInitialMarketOrders` 函数中的 `popularGoods` 列表也有多处ID偏移错误，需要与 `goods.ts` 对齐。

## 修复方案

### 步骤1：修复 AI 公司配置

需要修正以下 AI 公司的 `outputGoods` 数组：

| 公司名称 | 当前错误值 | 修正后正确值 |
|---------|-----------|-------------|
| 多金属矿业 | [132-137] | [128-133] |
| 有色冶炼 | starterGoods [132-137] → [128-133]<br>outputGoods [138-143] → [134-139] | 矿石→精炼金属 |
| 羊毛纺织 | [144, 145, 146] | [140, 141, 143] |
| 皮革制品 | [147-152] | [142, 144, 145, 146, 147, 148, 149] |
| 粘土建材 | [153-157] | [150, 151, 152, 153, 154] |
| 陶瓷卫浴 | [158-162] | [155, 156, 157, 158, 159] |
| 经济作物 | [163-168] | [160, 161, 162, 163, 164, 165] |
| 金龙鱼 | starterGoods 需修正 | [161, 165, 8] → [166, 167, 168] |
| 茅台集团 | starterGoods [163, 8, 169] | [160, 8, 166] |
| 星巴克供应 | starterGoods/outputGoods 修正 | 按正确ID |
| 中核集团 | [179, 181, 182, 183] | [176, 177, 178, 179, 180] |
| 特变电工 | [185, 186, 187, 188] | [182, 183, 184, 185] |
| 长飞光纤 | [189] | [186] |
| 华为设备 | [190-198] | [187-195] |
| 中国航天 | [196] | [193] |

### 步骤2：修复 popularGoods 列表

需要将 `generateInitialMarketOrders` 函数中的所有商品ID与 `goods.ts` 对齐。

### 步骤3：添加缺失的生产公司

某些原材料商品可能缺少专门的生产公司，需要添加：

1. **生物质采集** - 建筑80可以生产生物质(ID 177)，但目前中核集团只用建筑80开采铀矿
2. **大理石开采** - 需要建筑73，目前粘土建材只开采粘土

### 步骤4：验证配方与建筑的匹配

确保每个AI公司的 `buildings` 数组中的建筑类型与其 `outputGoods` 对应的配方匹配。

## 需要修改的文件

1. **`src/core/world/WorldInitializer.ts`**
   - 修复 `initializeAICompanies` 函数中所有AI公司的配置
   - 修复 `generateInitialMarketOrders` 函数中的 `popularGoods` 列表

## 预期结果

修复后：
- 所有230种商品都有对应的生产者
- 产业链完整，原材料→加工→成品的链条不会断裂
- 市场上所有商品都有买单和卖单

## 风险评估

- **低风险**：修改仅涉及数据配置，不改变逻辑
- **需要测试**：修复后需验证所有商品在市场页面正确显示和交易
